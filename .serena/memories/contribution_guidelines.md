# Contribution Guidelines

## Important Rules

### What NOT to Add
- **NO LeetCode problems** - The repository does not accept LeetCode-specific problems
- Only add fundamental algorithms and data structures

## How to Contribute

### 1. Reporting Bugs
- Search existing [issues](https://github.com/TheAlgorithms/Java/issues) first
- If bug exists and you can fix it:
  - Fork the repository
  - Submit implementation in a pull request
- If bug is new:
  - Open a new issue with:
    - Clear title
    - Detailed description
    - Test case demonstrating expected behavior

### 2. Contributing Documentation
- Fork the repository
- Make necessary changes
- Create a pull request
- Changes will be reviewed and merged if approved

### 3. Adding New Features
- Open a new issue first
- Include:
  - Clear title
  - Detailed description
  - Test case for the new feature
- Wait for feedback before implementing

### 4. Code Contributions
- Do NOT ask to be "assigned" to issues (creates noise)
- Instead: directly submit implementation via pull request
- Maintainers will evaluate the implementation

## Best Practices for PRs
- Follow existing code style and conventions
- Include comprehensive tests
- Add Javadoc documentation
- Ensure all quality checks pass:
  - Checkstyle
  - SpotBugs
  - PMD
  - All tests pass
- Keep changes focused and atomic
- Write clear commit messages
