# 📚 References

> Academic papers, textbooks, and authoritative resources

## Textbooks

### Foundational

1. **Cormen, T. H., Leiserson, C. E., Rivest, R. L., & Stein, C.**  
   *"Introduction to Algorithms"* (CLRS), 4th Edition, MIT Press, 2022.  
   The definitive algorithms textbook.

2. **Sedgewick, R. & Wayne, K.**  
   *"Algorithms"*, 4th Edition, Addison-Wesley, 2011.  
   Excellent Java-based algorithms course.

3. **Kleinberg, J. & Tardos, E.**  
   *"Algorithm Design"*, Pearson, 2005.  
   Great for algorithm design paradigms.

### Specialized

4. **Knuth, D. E.**  
   *"The Art of Computer Programming"*, Volumes 1-4A, Addison-Wesley.  
   Comprehensive reference for analysis and implementation.

5. **Skiena, S. S.**  
   *"The Algorithm Design Manual"*, 3rd Edition, Springer, 2020.  
   Practical focus with war stories.

6. **Weiss, M. A.**  
   *"Data Structures and Algorithm Analysis in Java"*, 3rd Edition, Pearson, 2012.  
   Java-specific implementation details.
