## ⚠️ Key Pitfalls Documented

### Graph Algorithms
- Negative edge handling in Dijkstra
- Integer overflow in distance calculations
- Disconnected graph handling
- Negative cycle detection

### Data Structures
- Height update after rotations (AVL/RB)
- Memory allocation for tree size
- B-Tree node splitting edge cases
- Segment tree identity elements

### Backtracking
- Stack overflow in deep recursion
- Incorrect diagonal checks (N-Queens)
- Off-by-one boundary errors
- Pruning optimization importance

### Cryptography
- ECB mode vulnerabilities
- IV/nonce reuse dangers
- Key derivation requirements
- Padding oracle attacks
